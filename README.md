# 🚀 ISS Space Tracker & Astronaut Finder

A real-time, responsive web dashboard that tracks the current location of the International Space Station (ISS) on an interactive map and displays the astronauts currently in orbit.

🌐 **Live Demo:** [Click Here to View Live App](https://somanadhgutla1-cmd.github.io/iss-tracker/)

---

## 🌟 Features
* **Live ISS Tracking:** Automatically updates the position of the ISS on an interactive map every 5 seconds.
* **Real-Time Coordinates:** Displays live Latitude and Longitude coordinates.
* **Astronaut Finder:** Fetches and displays the names of astronauts currently living aboard space stations.
* **Zero Installation Build:** Built entirely using modern web browser standards and client-side APIs.

---

## 🛠️ Tech Stack & APIs
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Mapping Library:** [Leaflet.js](https://leafletjs.com/) via CDN
* **APIs Used:**
  * [Where the ISS at? API](https://wheretheiss.at/) (For ISS coordinates)
  * [Open Notify API](http://open-notify.org/) (For astronaut manifest)

---

## 💻 How to Run Locally
No installation or node modules required!
1. Clone or download this repository.
2. Open `index.html` directly in any standard web browser.
